# Palladium
A programming language that compiles into Java, written in Rust

## Full Feature List
- [X] Output built in for System.out.println
- [X] Integer and Float support
- [X] Arithmetic operations: +, -, *, /
- [X] Comparison operations: <, <=, >, >=, ==
- [X] Variables and assignment
- [X] Loops
- [X] Loops with ranges (compile to for loops)
- [X] If statements
- [X] Functions and builtins
